# ポルトガル語学習教材

ブラジルポルトガル語を対象に、入門から初級〜中級（過去形・未来形を含む）までを扱う学習ノートです。

## 使い方

- 各レッスンは `lessons/` 以下にフォルダ単位で分かれています。
- 各レッスンフォルダには文法解説（`README.md`）と単語・フレーズ集（`vocabulary.md`）を用意します。
- 全レッスン共通で使う単語は `vocabulary/master-list.md` に累積していきます。
