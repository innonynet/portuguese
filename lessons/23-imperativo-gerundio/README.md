# レッスン23: 命令法・進行形

## 学習目標

- você に対する命令形(肯定・否定)を作れる
- 進行形(estar + gerúndio)を使って「〜している」を表現できる

## 1. 肯定命令形(você向け)

ブラジルの日常会話では `você` に対する命令が最もよく使われる。肯定命令形は接続法現在(後のレッスンで詳しく扱う)と同じ形になり、実用上は次のパターンで作れる。

| 原形 | você への肯定命令 |
| --- | --- |
| falar(話す) | fale |
| comer(食べる) | coma |
| abrir(開ける) | abra |

作り方の目安: -ar動詞は語尾を `-e` に、-er/-ir動詞は語尾を `-a` に変える(現在形の `eu` の形の語尾を入れ替えるイメージ)。

例: Fale mais devagar, por favor.(もっとゆっくり話してください)

## 2. 否定命令形

否定命令形はすべての人称で接続法の形を使う。作り方は肯定形と同じで、前に `não` をつけるだけ。

- Não fale alto.(大声で話さないでください)
- Não coma isso.(それを食べないでください)
- Não abra a janela.(窓を開けないでください)

## 3. 主な不規則命令形(você向け)

| 原形 | 肯定命令 |
| --- | --- |
| ir(行く) | vá |
| ser(〜である) | seja |
| ter(持つ) | tenha |
| fazer(する/作る) | faça |
| dizer(言う) | diga |

例: Vá em frente.(まっすぐ行ってください、[レッスン17](../17-direcoes-transporte/README.md)既出) / Tenha um bom dia!(良い一日を!)

## 4. 進行形: estar + gerúndio

「今〜している」という進行中の動作は `estar`(現在形)+ 動詞の gerúndio(現在分詞のような形)で表す。

### gerúndioの作り方

| 語尾 | gerúndio | 例 |
| --- | --- | --- |
| -ar → -ando | falando | falar → falando |
| -er → -endo | comendo | comer → comendo |
| -ir → -indo | abrindo | abrir → abrindo |

### 進行形の活用例(falar)

| 人称 | 活用 |
| --- | --- |
| eu | estou falando |
| tu | estás falando |
| você/ele/ela | está falando |
| nós | estamos falando |
| vós | estais falando |
| vocês/eles/elas | estão falando |

## 5. 例文

| ポルトガル語 | 日本語 |
| --- | --- |
| Espere um momento, por favor. | 少々お待ちください。 |
| Não se preocupe. | 心配しないでください。 |
| Eu estou estudando português agora. | 私は今ポルトガル語を勉強しています。 |
| Eles estão comendo no restaurante. | 彼らはレストランで食事をしています。 |

## 6. ミニ練習

次をポルトガル語にしよう(você向け命令形)。

1. 「ドアを開けてください」(abrir a porta)
2. 「心配しないでください」(否定命令、preocupar-se)

カッコの動詞を進行形にしよう。

3. Ela ___ (dormir).
4. Nós ___ (trabalhar) muito hoje.
