# レッスン13: 時間・曜日・月・天気

## 学習目標

- 時刻を尋ね、答えられる
- 曜日・月を言える
- 天気を表現できる

## 1. 時刻の言い方

「何時ですか」は `Que horas são?` [ki ˈɔɾɐz sɐ̃w̃]。答えは `São + 数字 + horas` が基本形だが、1時だけは単数扱いで `É uma hora` になる。

| ポルトガル語 | 日本語 |
| --- | --- |
| É uma hora. | 1時です。 |
| São duas horas. | 2時です。 |
| São três e meia. | 3時半です。(meia = 半分) |
| São quatro e quinze. | 4時15分です。 |
| São cinco para as seis. | 6時5分前です。(直訳: 6時まで5分) |
| da manhã / da tarde / da noite | 午前/午後/夜(時刻の後に添える) |

例: São sete da manhã.(朝7時です)

## 2. 曜日

| ポルトガル語 | IPA | 日本語 |
| --- | --- | --- |
| segunda-feira | [seˈɡũdɐ ˈfejɾɐ] | 月曜日 |
| terça-feira | [ˈteɾsɐ ˈfejɾɐ] | 火曜日 |
| quarta-feira | [ˈkwaɾtɐ ˈfejɾɐ] | 水曜日 |
| quinta-feira | [ˈkĩtɐ ˈfejɾɐ] | 木曜日 |
| sexta-feira | [ˈsestɐ ˈfejɾɐ] | 金曜日 |
| sábado | [ˈsabadu] | 土曜日 |
| domingo | [doˈmĩɡu] | 日曜日 |

月〜金は「2番目の祝日」「3番目の祝日」...という意味の `-feira` が語源(教会暦に由来)。会話では `-feira` を省略して `segunda`, `terça` などとだけ言うことも多い。

## 3. 月

| ポルトガル語 | 日本語 | ポルトガル語 | 日本語 |
| --- | --- | --- | --- |
| janeiro | 1月 | julho | 7月 |
| fevereiro | 2月 | agosto | 8月 |
| março | 3月 | setembro | 9月 |
| abril | 4月 | outubro | 10月 |
| maio | 5月 | novembro | 11月 |
| junho | 6月 | dezembro | 12月 |

日付は「日 + de + 月」の順: 10 de junho(6月10日)。

## 4. 天気の表現

| ポルトガル語 | 日本語 |
| --- | --- |
| Como está o tempo? | 天気はどうですか。 |
| Está fazendo sol. | 晴れています。 |
| Está chovendo. | 雨が降っています。 |
| Está nublado. | 曇っています。 |
| Faz calor. / Faz frio. | 暑いです。/寒いです。([レッスン10](../10-verbos-irregulares-comuns/README.md)の fazer 既出) |

## 5. 例文

| ポルトガル語 | 日本語 |
| --- | --- |
| A reunião é na quinta-feira. | 会議は木曜日です。 |
| Meu aniversário é em março. | 私の誕生日は3月です。 |
| Hoje está chovendo muito. | 今日は雨がたくさん降っています。 |

## 6. ミニ練習

次をポルトガル語にしよう。

1. 「7時半です」
2. 「金曜日」
3. 「12月」
4. 「晴れています」

<details>
<summary>解答</summary>

1. São sete e meia.
2. sexta-feira
3. dezembro
4. Está fazendo sol.

</details>
