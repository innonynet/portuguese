# レッスン04: 名詞の性・数と冠詞

## 学習目標

- 名詞の性(男性/女性)を見分ける基本ルールを知る
- 名詞を複数形にできる
- 定冠詞・不定冠詞を性・数に合わせて正しく使える

## 1. 名詞の性

ポルトガル語の名詞にはすべて文法上の性(男性/女性)がある。

### 基本ルール

| 語尾 | 性 | 例 |
| --- | --- | --- |
| -o | 男性 | o livro(本)、o carro(車) |
| -a | 女性 | a casa(家)、a mesa(テーブル) |
| -ção, -são | 女性 | a informação(情報)、a decisão(決定) |
| -dade | 女性 | a cidade(街)、a verdade(真実) |
| -ma(ギリシャ語源) | 男性 | o problema(問題)、o programa(プログラム) |

### 覚えておきたい例外

| 単語 | IPA | 性 | 日本語 |
| --- | --- | --- | --- |
| o dia | [u ˈdʒiɐ] | 男性(-aだが) | 日 |
| a mão | [a mɐ̃w̃] | 女性(-ãoだが) | 手 |
| a foto | [a ˈfɔtu] | 女性(-oだが) | 写真 |
| o mapa | [u ˈmapɐ] | 男性(-aだが) | 地図 |

-e や子音で終わる名詞(estudante, professor など)は規則だけでは性が分からないものが多く、単語ごとに冠詞とセットで覚えるのが確実。

## 2. 名詞の複数形

| 語尾のパターン | 変化 | 例 |
| --- | --- | --- |
| 母音で終わる | +s | casa → casas(家) |
| r, s, z で終わる | +es | mulher → mulheres(女性)、país → países(国) |
| m で終わる | m → ns | homem → homens(男性)、jovem → jovens(若者) |
| -ão で終わる(多くの場合) | -ão → -ões | ação → ações(行動) |
| -ão で終わる(一部) | -ão → -ães | pão → pães(パン)、cão → cães(犬) |
| -ão で終わる(一部) | -ão → -ãos | mão → mãos(手)、irmão → irmãos(兄弟) |
| l で終わる(多くの場合) | l → is | animal → animais(動物) |

`-ão` の複数形は3パターンあり、どの単語がどのパターンになるかは基本的に単語ごとに覚える必要がある。

## 3. 冠詞

冠詞は名詞の性・数に合わせて形が変わる。

### 定冠詞(「その〜」)

| | 単数 | 複数 |
| --- | --- | --- |
| 男性 | o | os |
| 女性 | a | as |

### 不定冠詞(「ある〜、1つの〜」)

| | 単数 | 複数 |
| --- | --- | --- |
| 男性 | um | uns |
| 女性 | uma | umas |

例:
- o livro(その本) / os livros(それらの本)
- uma casa(1つの家) / umas casas(いくつかの家)

国名の多くには定冠詞をつける(o Japão, o Brasil, a França)。ただし Portugal のように冠詞なしで使う国名もある。

## 4. 例文

| ポルトガル語 | 日本語 |
| --- | --- |
| O livro é bom. | その本は良い。 |
| Uma mulher está aqui. | 1人の女性がここにいる。 |
| Os pães estão na mesa. | パンたちがテーブルの上にある。 |
