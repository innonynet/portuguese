# レッスン12: 前置詞と縮約形

## 学習目標

- 基本前置詞(de, em, a, por, para, com)の意味を覚える
- 前置詞と定冠詞の縮約形を使える
- por と para の使い分けができる

## 1. 基本前置詞

| 前置詞 | IPA | 主な意味 |
| --- | --- | --- |
| de | [dʒi] | 〜の、〜から(出身・所属・材質) |
| em | [ẽj] | 〜に、〜で(場所・時間) |
| a | [a] | 〜へ、〜に(方向・間接目的語) |
| por | [poɾ] | 〜によって、〜のために(理由・経路・交換) |
| para | [ˈpaɾɐ] | 〜のために、〜へ(目的・宛先) |
| com | [kõ] | 〜と一緒に |

## 2. 前置詞 + 定冠詞の縮約形

`de`, `em`, `a`, `por` は定冠詞(o/a/os/as)と組み合わさると1語に縮約される。すでに[レッスン03](../03-apresentacao-pessoal/README.md)や[レッスン06](../06-verbo-estar-lugar/README.md)で `do`, `no` などが登場している。

| 前置詞 | + o | + a | + os | + as |
| --- | --- | --- | --- | --- |
| de | do | da | dos | das |
| em | no | na | nos | nas |
| a | ao | à | aos | às |
| por | pelo | pela | pelos | pelas |

`a + a → à` は[レッスン01](../01-alfabeto-pronuncia/README.md)で扱った acento grave(クラーズィ)そのもの。

例:
- Eu venho do Japão.(私は日本から来る) ← de + o Japão
- O livro está na mesa.(その本はテーブルの上にある) ← em + a mesa
- Vou ao mercado.(私は市場へ行く) ← a + o mercado
- Passeamos pela praia.(私たちは浜辺を散歩する) ← por + a praia

## 3. por と para の使い分け

どちらも英語の for に近い訳になることがあるが、意味が異なる。

| | por | para |
| --- | --- | --- |
| 意味の中心 | 理由・経路・交換・手段 | 目的・宛先・期限 |
| 例 | Obrigado por tudo.(すべてに感謝します=理由) | Este presente é para você.(このプレゼントはあなた宛です=宛先) |
| 例 | Passamos pelo parque.(公園を通り抜けた=経路) | Vou para São Paulo.(サンパウロへ行く=目的地) |
| 例 | Troquei o livro por outro.(その本を別のと交換した=交換) | Preciso disso para amanhã.(これは明日までに必要=期限) |

## 4. 例文

| ポルトガル語 | 日本語 |
| --- | --- |
| Eu moro em Tóquio. | 私は東京に住んでいます。 |
| Este presente é para minha mãe. | このプレゼントは私の母へのものです。 |
| Nós viajamos pelo Brasil. | 私たちはブラジル中を旅行しました。 |
| Ela trabalha com computadores. | 彼女はコンピューターを使って(共に)働いています。 |

## 5. ミニ練習

適切な縮約形・前置詞を入れよう。

1. Eu sou ___ Japão.(de + o)
2. O gato está ___ casa.(em + a)
3. Vamos ___ praia amanhã.(a + a)
4. Isso é ___ você.(目的・宛先)

<details>
<summary>解答</summary>

1. do
2. na
3. à
4. para

</details>
