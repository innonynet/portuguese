# レッスン08: 疑問詞と疑問文

## 学習目標

- 主要な疑問詞を覚える
- 疑問文の作り方(語順を変えずイントネーションで作る)を理解する
- por que の4つの書き分けを区別できる

## 1. 疑問詞一覧

| 疑問詞 | IPA | 日本語 | 例文 |
| --- | --- | --- | --- |
| O que | [u ki] | 何 | O que é isso?(それは何ですか) |
| Quem | [kẽj] | 誰 | Quem é você?(あなたは誰ですか) |
| Qual / Quais | [kwaw] / [kwajs] | どれ(単数/複数) | Qual é o seu nome?(あなたの名前は何ですか) |
| Onde | [ˈõdʒi] | どこ | Onde você mora?(あなたはどこに住んでいますか) |
| Quando | [ˈkwɐ̃du] | いつ | Quando é a festa?(パーティーはいつですか) |
| Como | [ˈkomu] | どのように | Como você está?(調子はどうですか) |
| Por que | [poɾ ˈke] | なぜ | Por que você estuda português?(なぜポルトガル語を勉強するのですか) |
| Quanto / Quanta / Quantos / Quantas | [ˈkwɐ̃tu] など | どれくらい(の量/数) | Quantos anos você tem?(あなたは何歳ですか) |

`Qual` は「どれ・何」を選択的に尋ねる時に使う(名前や具体的な1つを尋ねる場合など)。`Quanto` は名詞の性・数に一致して4つの形に変化する(quanto/quanta/quantos/quantas)。

## 2. 疑問文の作り方

ポルトガル語には英語のような主語と動詞の倒置(do you ~?のような形)がない。平叙文の語順のまま、文末に `?` をつけ、話す時は文末のイントネーションを上げるだけで疑問文になる。

| 平叙文 | 疑問文 |
| --- | --- |
| Você é brasileiro. (あなたはブラジル人です) | Você é brasileiro?(あなたはブラジル人ですか) |
| Ela mora aqui. (彼女はここに住んでいます) | Ela mora aqui?(彼女はここに住んでいますか) |

会話では文末に `né?`(〜だよね?、`não é?` の短縮形)をつけて確認する言い方もよく使う。

## 3. por que の4つの書き分け

| 表記 | 用法 | 例 |
| --- | --- | --- |
| por que(分かち書き、アクセント記号なし) | 疑問文で「なぜ」 | Por que você chegou tarde?(なぜ遅れて来たの?) |
| porque(1語、アクセント記号なし) | 答えの文で「なぜなら」 | Porque eu perdi o ônibus.(バスに乗り遅れたから) |
| por quê(分かち書き、アクセント記号あり) | 疑問文の文末で単独 | Você chegou tarde. Por quê?(遅れて来たね。なぜ?) |
| porquê(1語、アクセント記号あり) | 名詞「理由」 | Eu não sei o porquê.(私はその理由を知らない) |

## 4. 例文

| ポルトガル語 | 日本語 |
| --- | --- |
| O que você quer? | あなたは何が欲しいですか。 |
| Onde fica o banheiro? | トイレはどこにありますか。 |
| Quando você chega? | あなたはいつ着きますか。 |
| Quantas pessoas vêm à festa? | 何人がパーティーに来ますか。 |

## 5. ミニ練習

適切な疑問詞を入れよう。

1. ___ é o seu nome?(何)
2. ___ você mora?(どこ)
3. ___ custa isso?(どれくらい=いくら)
4. ___ você não veio ontem?(なぜ)

<details>
<summary>解答</summary>

1. Qual
2. Onde
3. Quanto
4. Por que

</details>
