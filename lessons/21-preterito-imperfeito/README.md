# レッスン21: 不完了過去

## 学習目標

- 不完了過去(Pretérito Imperfeito)を活用できる
- 習慣的な過去・過去の状況描写を表現できる
- 点過去(Pretérito Perfeito)との使い分けができる

## 1. -ar動詞: falar(話す)

| 人称 | 活用 | IPA |
| --- | --- | --- |
| eu | falava | [faˈlavɐ] |
| tu | falavas | [faˈlavɐs] |
| você/ele/ela | falava | [faˈlavɐ] |
| nós | falávamos | [faˈlavɐmus] |
| vós | faláveis | [faˈlavejs] |
| vocês/eles/elas | falavam | [faˈlavɐ̃w̃] |

## 2. -er/-ir動詞: comer(食べる)/ abrir(開ける)

-er動詞と-ir動詞は同じ語尾パターン(-ia系)を取る。

| 人称 | comer | abrir |
| --- | --- | --- |
| eu | comia | abria |
| tu | comias | abrias |
| você/ele/ela | comia | abria |
| nós | comíamos | abríamos |
| vós | comíeis | abríeis |
| vocês/eles/elas | comiam | abriam |

## 3. 主な不規則動詞: ser, ter

| 人称 | ser | ter |
| --- | --- | --- |
| eu | era | tinha |
| tu | eras | tinhas |
| você/ele/ela | era | tinha |
| nós | éramos | tínhamos |
| vós | éreis | tínheis |
| vocês/eles/elas | eram | tinham |

不完了過去はほとんどの動詞が規則的に活用するが、`ser` と `ter` はよく使うのでセットで覚えておくとよい。

## 4. 不完了過去の用法

| 用法 | 例 | 日本語 |
| --- | --- | --- |
| 習慣的な過去(〜したものだった) | Quando eu era criança, eu jogava futebol todos os dias. | 子供の頃、私は毎日サッカーをしたものだった。 |
| 過去の状況・背景描写 | O céu estava azul e fazia calor. | 空は青く、暑かった。 |
| 過去のある時点で進行中だったこと | Eu estudava quando ela chegou. | 彼女が着いた時、私は勉強していた。 |
| 丁寧な依頼([レッスン15](../15-comida-restaurante/README.md)既出) | Eu queria um café. | コーヒーをいただきたいのですが。 |

## 5. Perfeito と Imperfeito の使い分け

| | Pretérito Perfeito | Pretérito Imperfeito |
| --- | --- | --- |
| 性質 | 完了した1回の出来事 | 習慣・継続・背景描写 |
| 例 | Ontem eu comi pizza.(昨日ピザを食べた=1回) | Quando eu era criança, eu comia pizza toda sexta.(子供の頃、毎週金曜にピザを食べていた=習慣) |
| 焦点 | 出来事の始まりと終わり | 出来事の途中・状態 |

2つの時制はよく組み合わさる: 「〜していた時に、〜が起こった」は Imperfeito(背景)+ Perfeito(出来事)の形になる。

例: Eu dormia quando o telefone tocou.(電話が鳴った時、私は眠っていた) — dormia(Imperfeito、背景)、tocou(Perfeito、出来事)

## 6. 例文

| ポルトガル語 | 日本語 |
| --- | --- |
| Meu avô morava no interior. | 私の祖父は田舎に住んでいた。 |
| Nós éramos muito próximos. | 私たちはとても親しかった。 |
| Ela sempre chegava atrasada. | 彼女はいつも遅れて到着していた。 |

## 7. ミニ練習

カッコの動詞を不完了過去に活用しよう。

1. Quando eu ___ (ser) criança, eu ___ (morar) no Japão.
2. Nós ___ (ter) um cachorro quando éramos jovens.
3. Ele ___ (trabalhar) todos os dias naquela época.

<details>
<summary>解答</summary>

1. era / morava
2. tínhamos
3. trabalhava

</details>
