# レッスン17: 道案内・交通手段

## 学習目標

- 道を尋ね、簡単な道案内ができる
- 交通手段を表す言い方(de + 手段)を使える

## 1. 道を尋ねる

| ポルトガル語 | IPA | 日本語 |
| --- | --- | --- |
| Onde fica a estação? | [ˈõdʒi ˈfikɐ a estaˈsɐ̃w̃] | 駅はどこですか |
| Como chego a...? | [ˈkomu ˈʃeɡu a] | 〜へはどう行けばいいですか |
| É perto daqui? | [ɛ ˈpeɾtu daˈki] | ここから近いですか |
| É longe daqui? | [ɛ ˈlõʒi daˈki] | ここから遠いですか |

## 2. 道案内の表現

| ポルトガル語 | IPA | 日本語 |
| --- | --- | --- |
| Vá em frente. | [va ẽj ˈfɾẽtʃi] | まっすぐ行ってください |
| Vire à direita. | [ˈviɾi a dʒiˈɾejtɐ] | 右に曲がってください |
| Vire à esquerda. | [ˈviɾi a esˈkeɾdɐ] | 左に曲がってください |
| Atravesse a rua. | [atɾaˈvɛsi a ˈhuɐ] | 通りを渡ってください |
| na esquina | [na esˈkinɐ] | 角に |
| no sinal | [nu siˈnaw] | 信号のところに |
| depois de / antes de | [deˈpojz dʒi] / [ˈɐ̃tʃiz dʒi] | 〜の後に/〜の前に |

## 3. 交通手段

交通手段は `de + 手段` で表す(`de + o` は `do` に縮約される点に注意、[レッスン12](../12-preposicoes-contracoes/README.md)参照)。

| ポルトガル語 | IPA | 日本語 |
| --- | --- | --- |
| de ônibus | [dʒi ˈonibus] | バスで |
| de trem | [dʒi ˈtɾẽj] | 電車で |
| de metrô | [dʒi meˈtɾo] | 地下鉄で |
| de carro | [dʒi ˈkahu] | 車で |
| de táxi | [dʒi ˈtaksi] | タクシーで |
| de avião | [dʒi aviˈɐ̃w̃] | 飛行機で |
| de bicicleta | [dʒi bisiˈklɛtɐ] | 自転車で |
| a pé | [a ˈpɛ] | 徒歩で |

関連語: passagem(切符)、estação(駅)、ponto de ônibus(バス停)、aeroporto(空港)

## 4. 例文

| ポルトガル語 | 日本語 |
| --- | --- |
| Eu vou ao trabalho de metrô. | 私は地下鉄で仕事に行きます。 |
| A estação fica perto daqui. | 駅はここから近いです。 |
| Vire à direita na esquina. | 角を右に曲がってください。 |
| Quanto tempo leva de carro? | 車でどれくらい時間がかかりますか。 |

## 5. ミニ練習

次をポルトガル語にしよう。

1. 「駅はどこですか」
2. 「左に曲がってください」
3. 「バスで」
4. 「徒歩で」

<details>
<summary>解答</summary>

1. Onde fica a estação?
2. Vire à esquerda.
3. de ônibus
4. a pé

</details>
