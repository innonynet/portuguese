# レッスン16: 買い物・数量表現

## 学習目標

- 買い物の基本的なやり取りができる
- 数量を表す形容詞(多い/少ない/いくつか/すべて)を使える

## 1. 買い物での表現

| ポルトガル語 | IPA | 日本語 |
| --- | --- | --- |
| Quanto custa isso? | [ˈkwɐ̃tu ˈkustɐ ˈisu] | これはいくらですか |
| Posso experimentar? | [ˈpɔsu espeɾimẽˈtaɾ] | 試着/試食してもいいですか |
| Tem outra cor/tamanho? | [tẽj ˈotɾɐ koɾ/taˈmɐɲu] | 他の色/サイズはありますか |
| Vou levar este. | [vo leˈvaɾ ˈestʃi] | これを買います(直訳: 持っていきます) |
| Aceita cartão? | [aˈsejtɐ kaɾˈtɐ̃w̃] | カードは使えますか |
| Onde fica o caixa? | [ˈõdʒi ˈfikɐ u ˈkajʃɐ] | レジはどこですか |

## 2. 数量を表す形容詞

数量形容詞も修飾する名詞の性・数に一致する([レッスン11](../11-adjetivos-possessivos/README.md)の形容詞の一致を参照)。

| 男性単数 | 女性単数 | 男性複数 | 女性複数 | 日本語 |
| --- | --- | --- | --- | --- |
| muito | muita | muitos | muitas | たくさんの |
| pouco | pouca | poucos | poucas | 少しの |
| algum | alguma | alguns | algumas | いくつかの |
| nenhum | nenhuma | — | — | 全く〜ない |
| todo | toda | todos | todas | すべての |

例:
- Eu tenho muitos amigos.(私にはたくさんの友人がいる)
- Ela tem pouco tempo.(彼女はあまり時間がない)
- Não tenho nenhum problema.(私には何の問題もない)
- Todos os alunos chegaram.(すべての生徒が到着した)

数えられない量を表す時は `um pouco de`(少しの〜)、単位を使う時は `um quilo de`(1キロの〜)、`uma dúzia de`(1ダースの〜)のように `de` を挟む。

- um pouco de açúcar(少しの砂糖)
- um quilo de arroz(1キロの米)

## 3. 例文

| ポルトガル語 | 日本語 |
| --- | --- |
| Quanto custa este sapato? | この靴はいくらですか。 |
| Eu queria um quilo de maçã. | りんごを1キロいただきたいのですが。 |
| Tem alguma coisa mais barata? | もっと安いものはありますか。 |
| Aceita cartão de crédito? | クレジットカードは使えますか。 |

## 4. ミニ練習

適切な数量形容詞を選ぼう。

1. Ela tem ___(muito) dinheiro.
2. Eu tenho ___(pouco) tempo hoje.
3. ___(todo) as lojas estão fechadas.

<details>
<summary>解答</summary>

1. muito
2. pouco
3. Todas

</details>
