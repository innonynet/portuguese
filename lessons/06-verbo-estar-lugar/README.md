# レッスン06: estar動詞と場所・様子の表現

## 学習目標

- estar動詞を現在形で活用できる
- 場所や一時的な状態を表せる
- ser と estar の使い分けができる

## 1. estar動詞の現在形

| 人称 | 活用 | IPA |
| --- | --- | --- |
| eu | estou | [esˈto] |
| tu | estás | [esˈtas] |
| você / ele / ela | está | [esˈta] |
| nós | estamos | [esˈtɐmus] |
| vós | estais | [esˈtajs] |
| vocês / eles / elas | estão | [esˈtɐ̃w̃] |

## 2. estarの主な用法

| 用法 | 例 | 日本語 |
| --- | --- | --- |
| 物・人の場所 | A chave está na mesa. | 鍵はテーブルの上にある。 |
| 一時的な状態 | Eu estou cansado. | 私は(今)疲れている。 |
| 気分・体調 | Como você está? — Estou bem. | 調子はどう? — 元気です。 |
| 天候(口語) | Está frio hoje. | 今日は寒い。 |

`em`(〜に、〜で)は場所を表す基本前置詞で、`estar em + 場所` の形をよく使う。`em + o` は `no`、`em + a` は `na` に縮約される([レッスン12](../12-preposicoes-contracoes/README.md)で詳しく扱う)。

例: Eu estou em casa.(私は家にいる) / Ela está no Brasil.(彼女はブラジルにいる)

## 3. ser と estar の使い分け

どちらも「〜である/〜にある」に訳せるが、使い分けの基準が異なる。

| | ser | estar |
| --- | --- | --- |
| 性質 | 本質的・変わりにくい特徴 | 一時的な状態・条件 |
| 例 | Ele é alto.(彼は背が高い=生まれつきの特徴) | Ele está cansado.(彼は疲れている=今の状態) |
| 場所の対象 | 出来事の開催場所 | 人・物が今いる/ある場所 |
| 例 | A festa é na minha casa.(パーティーは私の家である) | Eu estou em casa.(私は今家にいる) |

同じ形容詞でも、ser を使うと恒常的な性質、estar を使うと一時的な状態というニュアンスの違いが出ることがある。

- Ela é bonita.(彼女は(いつも)きれいだ)
- Ela está bonita hoje.(彼女は今日きれいだ)

## 4. 例文

| ポルトガル語 | 日本語 |
| --- | --- |
| Onde você está? | あなたは今どこにいますか。 |
| Nós estamos na escola. | 私たちは学校にいます。 |
| Eu estou com fome. | 私はお腹が空いています。(直訳: 空腹と共にいる) |
| O café está quente. | そのコーヒーは(今)熱い。 |

## 5. ミニ練習

カッコに `ser` か `estar` の適切な活用を入れよう。

1. Eu ___ cansado hoje.(estar)
2. Ela ___ muito inteligente.(ser、本質的な性質)
3. A reunião ___ na sala 2.(ser、出来事の開催場所)
4. Nós ___ em casa agora.(estar、今いる場所)

<details>
<summary>解答</summary>

1. estou
2. é
3. é
4. estamos

</details>
