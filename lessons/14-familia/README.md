# レッスン14: 家族

## 学習目標

- 家族・親族の呼び方を覚える
- 自分の家族について簡単に説明できる

## 1. 核家族

| ポルトガル語(男性/女性) | IPA | 日本語 |
| --- | --- | --- |
| pai / mãe | [paj] / [mɐ̃j̃] | 父/母 |
| pais | [pajs] | 両親 |
| filho / filha | [ˈfiʎu] / [ˈfiʎɐ] | 息子/娘 |

| ポルトガル語(男性/女性) | IPA | 日本語 |
| --- | --- | --- |
| avô / avó | [aˈvo] / [aˈvɔ] | 祖父/祖母 |

| sogro / sogra | [ˈsoɡɾu] / [ˈsɔɡɾɐ] | 義父/義母 |
| cunhado / cunhada | [kuˈɲadu] / [kuˈɲadɐ] | 義兄弟/義姉妹 |

ポルトガル語の親族名称は、日本語の「兄・弟」「姉・妹」のような年上/年下の区別がなく、`irmão`(兄弟)、`irmã`(姉妹)だけで済む。年上/年下を言いたい場合は `irmão mais velho`(兄)、`irmão mais novo`(弟)のように付け加える。

## 3. 家族について話す表現

| ポルトガル語 | 日本語 |
| --- | --- |
| Quantos irmãos você tem? | あなたは兄弟が何人いますか。 |
| Eu tenho um irmão e uma irmã. | 私には兄弟が1人、姉妹が1人います。 |
| Minha família é grande. | 私の家族は大家族です。 |
| Este é o meu pai. | こちらは私の父です。 |

## 4. 例文

| ポルトガル語 | 日本語 |
| --- | --- |
| Meus avós moram no Japão. | 私の祖父母は日本に住んでいます。 |
| Ela tem dois filhos. | 彼女には子供が2人います。 |
| Meu irmão mais velho é engenheiro. | 私の兄はエンジニアです。 |

## 5. ミニ練習

次を自分自身のことに置き換えてポルトガル語で言ってみよう。

1. 兄弟・姉妹が何人いるか
2. 両親の職業(ser + 職業)
3. 「これは私の母です」

<details>
<summary>解答例</summary>

1. Eu tenho um irmão e uma irmã.
2. Meu pai é professor. Minha mãe é professora.
3. Esta é a minha mãe.

</details>
