# レッスン24: 比較級・最上級

## 学習目標

- 優等・劣等・同等の比較表現を作れる
- 不規則な比較級を覚える
- 最上級(相対・絶対)を作れる
- 複文をつなぐ基本的な接続詞を知る

## 1. 優等比較(〜より…だ)

`mais + 形容詞/副詞 + (do) que` の形。

- Ele é mais alto do que eu.(彼は私より背が高い)
- Este carro é mais caro que aquele.(この車はあの車より高い)

## 2. 劣等比較(〜ほど…でない)

`menos + 形容詞/副詞 + (do) que` の形。

- Ela é menos tímida do que ele.(彼女は彼ほど内気ではない)

## 3. 同等比較(〜と同じくらい…だ)

`tão + 形容詞/副詞 + quanto/como` の形。

- Ele é tão inteligente quanto ela.(彼は彼女と同じくらい賢い)

## 4. 不規則な比較級

一部の形容詞は `mais bom` のような規則形を使わず、専用の不規則な比較級を持つ。

| 原級 | 不規則な比較級 | 日本語 |
| --- | --- | --- |
| bom(良い) | melhor(より良い) | ×mais bomとは言わない |
| mau(悪い) | pior(より悪い) | ×mais mauとは言わない |
| grande(大きい) | maior(より大きい) | |
| pequeno(小さい) | menor(より小さい) | |

例: Este restaurante é melhor do que aquele.(このレストランはあれより良い)

## 5. 最上級

### 相対最上級(〜の中で一番…だ)

`o/a/os/as + mais/menos + 形容詞 + de/entre` の形。

- Ele é o mais alto da turma.(彼はクラスで一番背が高い)
- Esta é a melhor opção entre todas.(これがすべての中で一番良い選択肢だ)

### 絶対最上級(とても〜だ)

形容詞の語尾を `-íssimo/-íssima` に変えて「とても〜」という強調を表す。比較対象を必要としない。

| 原級 | 絶対最上級 | 日本語 |
| --- | --- | --- |
| lindo(美しい) | lindíssimo | とても美しい |
| grande(大きい) | grandíssimo | とても大きい |
| fácil(簡単な) | facílimo | とても簡単な |

例: Este lugar é lindíssimo!(この場所はとても美しい!)

## 6. 複文の基本接続詞

| 接続詞 | 日本語 |
| --- | --- |
| e | そして |
| mas | しかし |
| ou | または |
| porque | なぜなら([レッスン08](../08-perguntas-interrogativos/README.md)既出) |
| quando | 〜する時 |
| se | もし〜なら |
| que | 〜ということ(関係詞/接続詞) |

例:
- Eu gosto de café, mas prefiro chá.(私はコーヒーが好きだが、お茶の方が好きだ)
- Quando eu chegar, eu te ligo.(私が着いたら、あなたに電話する)
- Acho que ele tem razão.(私は彼が正しいと思う)

## 7. 例文

| ポルトガル語 | 日本語 |
| --- | --- |
| São Paulo é maior do que o Rio de Janeiro. | サンパウロはリオデジャネイロより大きい。 |
| Este é o melhor restaurante da cidade. | これは街で一番良いレストランだ。 |
| Ela fala português tão bem quanto uma nativa. | 彼女はネイティブと同じくらい上手にポルトガル語を話す。 |

## 8. ミニ練習

適切な比較・最上級表現を作ろう。

1. 「この本はあの本より面白い」(interessante)
2. 「これは私の人生で一番良い日だ」(o melhor dia)
3. 「とても大きい」(grande、絶対最上級)

<details>
<summary>解答</summary>

1. Este livro é mais interessante do que aquele.
2. Este é o melhor dia da minha vida.
3. grandíssimo

</details>
