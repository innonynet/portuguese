# レッスン18: 日課・頻度副詞・体調表現

## 学習目標

- 日課を表す動詞(再帰動詞を含む)を使える
- 頻度副詞を使って習慣を表現できる
- 体調・症状を表現できる

## 1. 日課の表現

日課には「〜する」(他動詞的)ではなく「自分自身を〜する」という再帰動詞がよく使われる。再帰動詞は再帰代名詞(me, te, se, nos, vos, se)を伴う。

| ポルトガル語 | IPA | 日本語 |
| --- | --- | --- |
| acordar | [akoɾˈdaɾ] | 目覚める |
| levantar-se | [levɐ̃ˈtaɾ si] | 起きる |
| tomar banho | [toˈmaɾ ˈbɐɲu] | シャワーを浴びる |
| escovar os dentes | [eskoˈvaɾ uz ˈdẽtʃis] | 歯を磨く |
| vestir-se | [vesˈtʃiɾ si] | 服を着る |
| tomar café da manhã | [toˈmaɾ kaˈfɛ dɐ mɐˈɲɐ̃] | 朝食を取る |
| ir trabalhar | [iɾ tɾabaˈʎaɾ] | 仕事に行く |
| voltar para casa | [vowˈtaɾ ˈpaɾɐ ˈkazɐ] | 家に帰る |
| dormir | [doɾˈmiɾ] | 眠る |

`levantar-se`(起きる)の現在形活用:

| 人称 | 活用 |
| --- | --- |
| eu | me levanto |
| tu | te levantas |
| você/ele/ela | se levanta |
| nós | nos levantamos |
| vós | vos levantais |
| vocês/eles/elas | se levantam |

再帰代名詞は主語に応じて変わり、活用した動詞の前(または話し言葉では後ろにハイフンでつなげる形)に置く。

## 2. 頻度副詞

| ポルトガル語 | IPA | 日本語 |
| --- | --- | --- |
| sempre | [ˈsẽpɾi] | いつも |
| geralmente / normalmente | [ʒeɾawˈmẽtʃi] / [noɾmawˈmẽtʃi] | 普段は |
| às vezes | [az ˈvezis] | 時々 |
| raramente | [haɾaˈmẽtʃi] | めったに〜ない |
| nunca | [ˈnũkɐ] | 決して〜ない |
| todos os dias | [ˈtoduz uz ˈdʒiɐs] | 毎日 |

頻度副詞は通常、動詞の前に置く。ただし `todos os dias` のような句は文末に置くことが多い。

例: Eu sempre tomo café da manhã.(私はいつも朝食を取る) / Eu estudo português todos os dias.(私は毎日ポルトガル語を勉強する)

## 3. 体調・症状の表現

体調・症状は `estar com + 症状` の形で表すことが多い([レッスン06](../06-verbo-estar-lugar/README.md)の estar 既出)。

| ポルトガル語 | IPA | 日本語 |
| --- | --- | --- |
| Como você está se sentindo? | [ˈkomu voˈse esˈta si sẽˈtʃĩdu] | 気分はどうですか |
| Estou com dor de cabeça. | [esˈto kõ doɾ dʒi kaˈbesɐ] | 頭が痛いです |
| Estou com dor de barriga. | [esˈto kõ doɾ dʒi baˈhiɡɐ] | お腹が痛いです |
| Estou com dor de garganta. | [esˈto kõ doɾ dʒi ɡaɾˈɡɐ̃tɐ] | 喉が痛いです |
| Estou gripado. / gripada. | [esˈto ɡɾiˈpadu] / [ɡɾiˈpadɐ] | 風邪をひいています |
| Preciso ir ao médico. | [pɾeˈsizu iɾ aw ˈmɛdʒiku] | 医者に行く必要があります |

## 4. 例文

| ポルトガル語 | 日本語 |
| --- | --- |
| Eu me levanto às sete horas todos os dias. | 私は毎日7時に起きます。 |
| Ele quase nunca bebe café. | 彼はほとんどコーヒーを飲みません。 |
| Estou com dor de cabeça hoje. | 今日は頭が痛いです。 |

## 5. ミニ練習

次をポルトガル語にしよう。

1. 「私は毎日歯を磨きます」
2. 「時々」
3. 「頭が痛いです」

<details>
<summary>解答</summary>

1. Eu escovo os dentes todos os dias.
2. às vezes
3. Estou com dor de cabeça.

</details>
