# レッスン05: 主語人称代名詞とser動詞

## 学習目標

- 主語人称代名詞を覚える
- ser動詞(英語のbeにあたる)を現在形で活用できる
- serの主な用法(身分・出身・性質・時間)を理解する

## 1. 主語人称代名詞

| 人称 | 単数 | 複数 |
| --- | --- | --- |
| 1人称 | eu [ew](私) | nós [nɔs](私たち) |
| 2人称 | tu [tu](君) | vós [vɔs](君たち、現代ではほぼ使わない) |
| 3人称 | você [voˈse](あなた)、ele [ˈeli](彼)、ela [ˈɛlɐ](彼女) | vocês [voˈses](あなたたち)、eles [ˈelis](彼ら)、elas [ˈɛlɐs](彼女たち) |

ブラジルでは日常会話の「あなた/君」は `tu` より `você` が主流(ただし地域によっては `tu` も使われる)。`você` は意味は2人称だが、文法上は3人称として扱う(動詞の活用が ele/ela と同じ形になる)。`vós` は聖書や古い文語以外ではほとんど使われない。

## 2. ser動詞の現在形

| 人称 | 活用 | IPA |
| --- | --- | --- |
| eu | sou | [so] |
| tu | és | [ɛs] |
| você / ele / ela | é | [ɛ] |
| nós | somos | [ˈsomus] |
| vós | sois | [ˈsɔjs] |
| vocês / eles / elas | são | [sɐ̃w̃] |

## 3. serの主な用法

| 用法 | 例 | 日本語 |
| --- | --- | --- |
| 身分・名前 | Eu sou Hiroshi. | 私はヒロシです。 |
| 出身・国籍 | Ela é do Brasil. / Ela é brasileira. | 彼女はブラジル出身です。/ブラジル人です。 |
| 職業 | Nós somos estudantes. | 私たちは学生です。 |
| 本質的な性質 | Ele é inteligente. | 彼は賢い。 |
| 曜日・日付・時刻 | Hoje é segunda-feira. | 今日は月曜日です。 |
| 材質・所有 | A mesa é de madeira. | そのテーブルは木製です。 |

`ser` は「変わりにくい・本質的な」性質や恒常的な状態を表す。一時的な状態や場所を表す `estar` との違いは[レッスン06](../06-verbo-estar-lugar/README.md)で扱う。

## 4. 例文

| ポルトガル語 | 日本語 |
| --- | --- |
| Eu sou japonês. | 私は日本人です。 |
| Você é professora? | あなたは(女性の)先生ですか。 |
| Nós somos amigos. | 私たちは友人です。 |
| Eles são brasileiros. | 彼らはブラジル人です。 |

## 5. ミニ練習

カッコに `ser` の適切な活用を入れよう。

3. Nós ___ professores.
4. Elas ___ japonesas.
