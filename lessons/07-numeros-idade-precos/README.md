# レッスン07: 数字・年齢・値段

## 学習目標

- 0〜100以上の基数詞を言える
- 年齢の尋ね方・答え方を知る
- 値段の尋ね方・答え方を知る

## 1. 数字 0〜20

| 数字 | ポルトガル語 | IPA |
| --- | --- | --- |
| 0 | zero | [ˈzɛɾu] |
| 1 | um / uma | [ũ] / [ˈumɐ] |
| 2 | dois / duas | [dojs] / [ˈduɐs] |
| 3 | três | [tɾes] |
| 4 | quatro | [ˈkwatɾu] |
| 5 | cinco | [ˈsĩku] |
| 6 | seis | [sejs] |
| 7 | sete | [ˈsɛtʃi] |
| 8 | oito | [ˈojtu] |
| 9 | nove | [ˈnɔvi] |
| 10 | dez | [dɛs] |
| 11 | onze | [ˈõzi] |
| 12 | doze | [ˈdozi] |
| 13 | treze | [ˈtɾezi] |
| 14 | quatorze | [kwaˈtoɾzi] |
| 15 | quinze | [ˈkĩzi] |
| 16 | dezesseis | [dezeˈsejs] |
| 17 | dezessete | [dezeˈsɛtʃi] |
| 18 | dezoito | [deˈzojtu] |
| 19 | dezenove | [dezeˈnɔvi] |
| 20 | vinte | [ˈvĩtʃi] |

`um`(1)と `dois`(2)は名詞の性に合わせて `uma`, `duas` になる。例: um livro(1冊の本) / uma casa(1軒の家)、dois livros(2冊の本) / duas casas(2軒の家)。3以上の数字は性による変化がない。

## 2. 数字 21〜100

| 数字 | ポルトガル語 |
| --- | --- |
| 21 | vinte e um |
| 30 | trinta |
| 40 | quarenta |
| 50 | cinquenta |
| 60 | sessenta |
| 70 | setenta |
| 80 | oitenta |
| 90 | noventa |
| 100 | cem |

21以降は「十の位 + e + 一の位」の形。例: vinte e um(21)、trinta e cinco(35)、noventa e nove(99)。

## 3. 年齢の言い方

年齢は `ter(持つ)+ 数字 + anos(歳)` で表す。英語の be動詞と違い、ポルトガル語では「歳を持つ」という言い方をする。`ter` の活用は[レッスン10](../10-verbos-irregulares-comuns/README.md)で扱うので、ここではセットで覚える。

| ポルトガル語 | 日本語 |
| --- | --- |
| Quantos anos você tem? | あなたは何歳ですか。 |
| Eu tenho trinta anos. | 私は30歳です。 |
| Ela tem vinte e cinco anos. | 彼女は25歳です。 |

## 4. 値段の尋ね方

| ポルトガル語 | IPA | 日本語 |
| --- | --- | --- |
| Quanto custa? | [ˈkwɐ̃tu ˈkustɐ] | いくらですか(直訳: いくら要りますか) |
| Quanto é? | [ˈkwɐ̃tu ɛ] | いくらですか |
| São dez reais. | [sɐ̃w̃ dɛs ʁeˈajs] | 10レアルです |

ブラジルの通貨単位は `real`(複数形 `reais`)。金額を言う時は数字のあとに `reais` を続ける。

## 5. 例文

| ポルトガル語 | 日本語 |
| --- | --- |
| Eu tenho dois irmãos. | 私には兄弟が2人います。 |
| Este livro custa vinte reais. | この本は20レアルです。 |
| Quantos anos ele tem? | 彼は何歳ですか。 |

## 6. ミニ練習

次をポルトガル語にしよう。

1. 15(数字)
2. 42(数字)
3. 「あなたは何歳ですか」
