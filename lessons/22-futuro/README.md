# レッスン22: 未来形

## 学習目標

- 近接未来(ir + 動詞の原形)を使える
- 単純未来形を活用できる
- 2つの未来表現の使い分けを理解する

## 1. 近接未来(Futuro Próximo): ir + 動詞の原形

[レッスン10](../10-verbos-irregulares-comuns/README.md)で少し触れた形。`ir` を活用し、そのあとに動詞の原形を続けるだけで作れる、日常会話で最もよく使われる未来表現。

| 人称 | 活用 |
| --- | --- |
| eu | vou falar |
| tu | vais falar |
| você/ele/ela | vai falar |
| nós | vamos falar |
| vós | ides falar |
| vocês/eles/elas | vão falar |

例: Eu vou viajar amanhã.(私は明日旅行する予定だ)

## 2. 単純未来形(Futuro do Presente)

動詞の原形に決まった語尾をつける形で、-ar/-er/-ir の3グループとも同じ語尾になる。

| 人称 | 語尾 | falar | comer | abrir |
| --- | --- | --- | --- | --- |
| eu | -ei | falarei | comerei | abrirei |
| tu | -ás | falarás | comerás | abrirás |
| você/ele/ela | -á | falará | comerá | abrirá |
| nós | -emos | falaremos | comeremos | abriremos |
| vós | -eis | falareis | comereis | abrireis |
| vocês/eles/elas | -ão | falarão | comerão | abrirão |

### 不規則な語幹を持つ動詞

| 原形 | 未来の語幹 | eu の形 |
| --- | --- | --- |
| fazer(する/作る) | far- | farei |
| dizer(言う) | dir- | direi |
| trazer(持ってくる) | trar- | trarei |

これら3つ以外は原形をそのまま語幹として使うため、単純未来は不規則動詞が少なく規則的に作りやすい時制と言える。

## 3. 2つの未来表現の使い分け

| | 近接未来(ir + 原形) | 単純未来 |
| --- | --- | --- |
| よく使う場面 | 日常会話(話し言葉) | 書き言葉、フォーマルな場面、確約・予測 |
| ニュアンス | 「〜するつもり」に近い、話者の意図が強い | 「〜だろう」に近い、より客観的・不確実 |
| 例 | Vou estudar hoje à noite. | Estudarei mais no futuro. |

ブラジルの日常会話では近接未来の方が圧倒的によく使われる。単純未来は約束・宣言・やや堅い文脈でよく見られる。

## 4. 例文

| ポルトガル語 | 日本語 |
| --- | --- |
| Amanhã eu vou trabalhar até tarde. | 明日、私は遅くまで働く予定だ。 |
| Nós vamos viajar para o Brasil no próximo ano. | 私たちは来年ブラジルへ旅行する予定だ。 |
| Eu farei o meu melhor. | 私は最善を尽くします。 |
| Ela dirá a verdade. | 彼女は真実を言うだろう。 |

## 5. ミニ練習

次をポルトガル語(近接未来)にしよう。

1. 「私は勉強するつもりです」
2. 「彼らは旅行する予定だ」

カッコの動詞を単純未来に活用しよう。

3. Eu ___ (fazer) tudo o que puder.
4. Nós ___ (falar) sobre isso amanhã.

<details>
<summary>解答</summary>

1. Eu vou estudar.
2. Eles vão viajar.
3. farei
4. falaremos
