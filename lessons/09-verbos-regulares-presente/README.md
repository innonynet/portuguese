# レッスン09: 規則動詞の現在形

## 学習目標

- -ar, -er, -ir 動詞の現在形活用パターンを覚える
- よく使う規則動詞で簡単な文を作れる

ポルトガル語の動詞は原形の語尾によって3グループ(-ar, -er, -ir)に分かれ、それぞれ決まった活用パターンを持つ。

## 1. -ar動詞: falar(話す)

| 人称 | 活用 | IPA |
| --- | --- | --- |
| eu | falo | [ˈfalu] |
| tu | falas | [ˈfalɐs] |
| você / ele / ela | fala | [ˈfalɐ] |
| nós | falamos | [faˈlɐmus] |
| vós | falais | [faˈlajs] |
| vocês / eles / elas | falam | [ˈfalɐ̃w̃] |

語尾の変化: -o, -as, -a, -amos, -ais, -am

## 2. -er動詞: comer(食べる)

| 人称 | 活用 | IPA |
| --- | --- | --- |
| eu | como | [ˈkomu] |
| tu | comes | [ˈkɔmis] |
| você / ele / ela | come | [ˈkɔmi] |
| nós | comemos | [koˈmemus] |
| vós | comeis | [koˈmejs] |
| vocês / eles / elas | comem | [ˈkɔmẽj] |

語尾の変化: -o, -es, -e, -emos, -eis, -em

## 3. -ir動詞: abrir(開ける)

| 人称 | 活用 | IPA |
| --- | --- | --- |
| eu | abro | [ˈabɾu] |
| tu | abres | [ˈabɾis] |
| você / ele / ela | abre | [ˈabɾi] |
| nós | abrimos | [aˈbɾimus] |
| vós | abris | [aˈbɾis] |
| vocês / eles / elas | abrem | [ˈabɾẽj] |

語尾の変化: -o, -es, -e, -imos, -is, -em

3グループとも `eu` の形は `-o` で終わり、`nós` の形にアクセントが来るという共通点がある。

## 4. よく使う規則動詞

| -ar動詞 | 日本語 | -er動詞 | 日本語 | -ir動詞 | 日本語 |
| --- | --- | --- | --- | --- | --- |
| estudar | 勉強する | vender | 売る | partir | 出発する |
| trabalhar | 働く | aprender | 学ぶ | assistir | 見る(番組など) |
| morar | 住む | correr | 走る | decidir | 決める |
| comprar | 買う | entender | 理解する | | |
| gostar (de) | 好きだ | beber | 飲む | | |
| chegar | 到着する | | | | |

`gostar` は「〜が好き」を表す時に前置詞 `de` を伴う: Eu gosto de café.(私はコーヒーが好きだ)

## 5. 例文

| ポルトガル語 | 日本語 |
| --- | --- |
| Eu trabalho em uma empresa japonesa. | 私は日本の会社で働いています。 |
| Nós estudamos português todos os dias. | 私たちは毎日ポルトガル語を勉強しています。 |
| Ela come arroz e feijão. | 彼女は米と豆を食べます。 |
| Eles vendem frutas no mercado. | 彼らは市場で果物を売っています。 |

## 6. ミニ練習

カッコの動詞を主語に合わせて活用しよう。

1. Eu ___ (falar) português.
2. Você ___ (comer) frutas?
3. Nós ___ (morar) no Japão.
4. Elas ___ (assistir) televisão.

<details>
<summary>解答</summary>

1. falo
2. come
3. moramos
4. assistem

</details>
