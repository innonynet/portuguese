# レッスン19: 過去形(規則動詞)

## 学習目標

- 規則動詞の点過去(Pretérito Perfeito)を活用できる
- 完了した過去の出来事を表現できる

## 1. Pretérito Perfeitoとは

`Pretérito Perfeito`(点過去)は、過去のある時点で完了した出来事を表す時制で、英語の単純過去(simple past)に近い。「昨日〜した」「先週〜した」のような、始まりと終わりがはっきりした過去の行為に使う。習慣的・継続的な過去を表す `Pretérito Imperfeito`(不完了過去)とは異なる時制で、この違いは[レッスン21](../21-preterito-imperfeito/README.md)で扱う。

## 2. -ar動詞: falar(話す)

| 人称 | 活用 | IPA |
| --- | --- | --- |
| eu | falei | [faˈlej] |
| tu | falaste | [faˈlastʃi] |
| você/ele/ela | falou | [faˈlo] |
| nós | falamos | [faˈlɐmus] |
| vós | falastes | [faˈlastʃis] |
| vocês/eles/elas | falaram | [faˈlaɾɐ̃w̃] |

## 3. -er動詞: comer(食べる)

| 人称 | 活用 | IPA |

| eu | comi | [koˈmi] |
| tu | comeste | [koˈmestʃi] |
| você/ele/ela | comeu | [koˈmew] |
| nós | comemos | [koˈmemus] |
| vós | comestes | [koˈmestʃis] |
| vocês/eles/elas | comeram | [koˈmeɾɐ̃w̃] |

## 4. -ir動詞: abrir(開ける)

| 人称 | 活用 | IPA |
| --- | --- | --- |
| eu | abri | [aˈbɾi] |
| tu | abriste | [aˈbɾistʃi] |
| você/ele/ela | abriu | [aˈbɾiw] |
| nós | abrimos | [aˈbɾimus] |
| vós | abristes | [aˈbɾistʃis] |
| vocês/eles/elas | abriram | [aˈbɾiɾɐ̃w̃] |

**注意**: `nós` の形は現在形と同じ形になる(falamos, comemos, abrimos)。過去か現在かは文脈(時間を表す語句など)で判断する。

## 5. 過去を表す時間表現

| ポルトガル語 | 日本語 |
| --- | --- |
| ontem | 昨日 |
| anteontem | 一昨日 |
| na semana passada | 先週 |
| no mês passado | 先月 |
| no ano passado | 去年 |
| há dois dias | 2日前に |

## 6. 例文

| ポルトガル語 | 日本語 |
| --- | --- |
| Eu falei com ela ontem. | 私は昨日彼女と話した。 |
| Nós comemos pizza na semana passada. | 私たちは先週ピザを食べた。 |
| Ele abriu a loja às oito. | 彼は8時に店を開けた。 |
| Vocês estudaram para a prova? | あなたたちは試験のために勉強しましたか。 |

## 7. ミニ練習

カッコの動詞を点過去に活用しよう。

1. Eu ___ (falar) japonês na reunião.
2. Ela ___ (comer) um sanduíche.
3. Nós ___ (morar) em São Paulo em 2020.
4. Eles ___ (abrir) o restaurante ontem.

<details>
<summary>解答</summary>

1. falei
2. comeu
3. moramos
4. abriram

</details>
