# レッスン01: アルファベットと発音

## 学習目標

- ブラジルポルトガル語のアルファベットを読める
- IPA(国際音声記号)を使って、文字と音の対応関係を理解する
- 日本語話者が特につまずきやすい音(鼻母音、lh/nh、口蓋化)を区別できる

## 2. 特に注意すべき音

日本語話者がつまずきやすい音を優先的に挙げる。

- **鼻母音**: 母音の後に `~`(til)や `m`/`n` が続くと鼻にかかる音になる。
  - ão: [ɐ̃w̃] 例: não [nɐ̃w̃](いいえ)
  - ãe: [ɐ̃j̃] 例: mãe [mɐ̃j̃](母)
  - õe: [õj̃] 例: põe [põj̃](置く、3人称単数)
- **nh**: /ɲ/ — 日本語の「にゃ・にゅ・にょ」に近い。例: ninho [ˈniɲu](巣)
- **lh**: /ʎ/ — 「りゃ・りゅ・りょ」に近い。例: filho [ˈfiʎu](息子)
- **口蓋化(ブラジル式)**: de, di, te, ti は「ヂ」「チ」寄りになる。
  - dia [ˈdʒiɐ](日)、tio [ˈtʃiu](叔父)
- **r の2種類**: 語頭や rr は喉の奥で出す [h]〜[x](日本語のハ行に近いことが多い、地域差あり)。語中の単一 r は舌先で弾く [ɾ](日本語のラ行に近い)。
  - rato [ˈhatu](ねずみ) vs. caro [ˈkaɾu](高価な)
