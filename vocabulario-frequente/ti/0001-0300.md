# IT関連用語 1〜300

日常のIT・テクノロジー分野でよく使われる語彙300語。書式については[README](../README.md)を参照。ブラジルポルトガル語のIT用語は英語からの借用語が非常に多い(software, internet, e-mail など)。

## 1〜100(ハードウェア・基本ソフトウェア)

**0001. computador** *[kõputaˈdoɾ]* — コンピューター
> 例: Meu computador está muito lento. — 私のコンピューターはとても遅い。

**0002. notebook** *[ˈnotʃibuki]* — ノートパソコン
> 例: Comprei um notebook novo para trabalhar. — 私は仕事用に新しいノートパソコンを買った。
> 注意: ブラジルでは「laptop」より「notebook」の方が一般的。

**0003. tela** *[ˈtelɐ]* — 画面
> 例: A tela do celular quebrou. — 携帯電話の画面が割れた。

**0004. monitor** *[moniˈtoɾ]* — モニター
> 例: Uso dois monitores para trabalhar. — 私は仕事に2台のモニターを使っている。

**0005. teclado** *[tekˈladu]* — キーボード
> 例: O teclado está com uma tecla travada. — キーボードのキーが1つ引っかかっている。

**0006. mouse** *[ˈmawzi]* — マウス
> 例: O mouse sem fio acabou a bateria. — ワイヤレスマウスの電池が切れた。

**0007. impressora** *[ĩpɾeˈsoɾɐ]* — プリンター
> 例: A impressora está sem tinta. — プリンターのインクが切れている。

**0008. processador** *[pɾosesaˈdoɾ]* — プロセッサー
> 例: Este processador é muito rápido. — このプロセッサーはとても速い。

**0009. memória** *[meˈmɔɾjɐ]* — メモリー
> 例: Preciso de mais memória neste computador. — このコンピューターにはもっとメモリーが必要だ。

**0010. disco rígido** *[ˈdʒisku ˈhiʒidu]* — ハードディスク
> 例: O disco rígido está quase cheio. — ハードディスクがほぼ満杯だ。
> 注意: 略して「HD」とも言う。

**0011. placa-mãe** *[ˈplakɐ ˈmɐ̃j̃]* — マザーボード
> 例: A placa-mãe queimou. — マザーボードが焼けた(壊れた)。

**0012. placa de vídeo** *[ˈplakɐ dʒi ˈvidʒju]* — グラフィックカード
> 例: Ele trocou a placa de vídeo para jogar melhor. — 彼はもっと快適にゲームをするためにグラフィックカードを交換した。

**0013. bateria** *[bateˈɾiɐ]* — バッテリー
> 例: A bateria do celular acaba rápido. — 携帯電話のバッテリーはすぐなくなる。

**0014. carregador** *[kahegaˈdoɾ]* — 充電器
> 例: Esqueci o carregador em casa. — 充電器を家に忘れた。

**0015. cabo** *[ˈkabu]* — ケーブル
> 例: Preciso de um cabo USB. — USBケーブルが必要だ。

**0016. alto-falante** *[ˈawtu faˈlɐ̃tʃi]* — スピーカー
> 例: O som do alto-falante está distorcido. — スピーカーの音が歪んでいる。

**0017. fone de ouvido** *[ˈfoni dʒi oˈvidu]* — イヤホン、ヘッドホン
> 例: Uso fone de ouvido para trabalhar. — 私は仕事の際にイヤホンを使う。

**0018. câmera** *[ˈkɐmeɾɐ]* — カメラ
> 例: A câmera do celular tira fotos ótimas. — その携帯のカメラは素晴らしい写真を撮る。

**0019. microfone** *[mikɾoˈfoni]* — マイク
> 例: O microfone não está funcionando na reunião. — 会議でマイクが機能していない。

**0020. roteador** *[hoteaˈdoɾ]* — ルーター
> 例: Preciso reiniciar o roteador. — ルーターを再起動する必要がある。

**0021. servidor** *[seɾviˈdoɾ]* — サーバー
> 例: O servidor caiu de novo. — サーバーがまたダウンした。

**0022. dispositivo** *[dʒispoziˈtʃivu]* — デバイス、機器
> 例: Conecte o dispositivo ao Wi-Fi. — デバイスをWi-Fiに接続してください。

**0023. hardware** *[aɾˈdwɛɾi]* — ハードウェア
> 例: O problema é de hardware, não de software. — 問題はソフトウェアではなくハードウェアだ。

**0024. software** *[ˈsɔftweɾi]* — ソフトウェア
> 例: Este software é gratuito. — このソフトウェアは無料だ。

**0025. chip** *[ˈʃipi]* — チップ
> 例: O celular tem um novo chip mais rápido. — その携帯電話にはより速い新しいチップが搭載されている。

**0026. pendrive** *[ˈpẽdɾajvi]* — USBメモリー
> 例: Salvei os arquivos no pendrive. — 私はファイルをUSBメモリーに保存した。

**0027. HD externo** *[ˈaɡɐ ˈdʒi esˈtɛɾnu]* — 外付けハードディスク
> 例: Faço backup no HD externo toda semana. — 私は毎週外付けハードディスクにバックアップを取っている。

**0028. cartão de memória** *[kaɾˈtɐ̃w̃ dʒi meˈmɔɾjɐ]* — メモリーカード
> 例: A câmera precisa de um cartão de memória. — そのカメラにはメモリーカードが必要だ。

**0029. tablet** *[ˈtableti]* — タブレット
> 例: Meu filho usa o tablet para estudar. — 私の息子は勉強にタブレットを使う。

**0030. smartphone** *[ˈsmaɾtfoni]* — スマートフォン
> 例: Quase todo mundo tem smartphone hoje em dia. — 今日ではほとんど誰もがスマートフォンを持っている。

**0031. celular** *[seluˈlaɾ]* — 携帯電話
> 例: Perdi meu celular no metrô. — 私は地下鉄で携帯電話をなくした。
> 注意: ブラジルでは「celular」が一般的、「smartphone」も併用される。

**0032. programa** *[pɾoˈɡɾɐmɐ]* — プログラム
> 例: Este programa trava toda hora. — このプログラムはしょっちゅうフリーズする。

**0033. aplicativo** *[apliˈkatʃivu]* — アプリ
> 例: Baixei um novo aplicativo de finanças. — 私は新しい家計簿アプリをダウンロードした。
> 注意: 口語では短縮して「app」もよく使う。

**0034. sistema operacional** *[sisˈtemɐ opeɾasjoˈnaw]* — オペレーティングシステム
> 例: Qual sistema operacional você usa? — どのOSを使っていますか。

**0035. navegador** *[naveɡaˈdoɾ]* — (ウェブ)ブラウザ
> 例: Meu navegador está desatualizado. — 私のブラウザは古くなっている。

**0036. editor de texto** *[ediˈtoɾ dʒi ˈtestu]* — テキストエディタ
> 例: Uso esse editor de texto para escrever código. — 私はコードを書くのにこのテキストエディタを使う。

**0037. planilha** *[plaˈniʎɐ]* — 表計算(スプレッドシート)
> 例: Organizei os dados em uma planilha. — 私はデータを表計算にまとめた。

**0038. antivírus** *[ɐ̃tʃiˈviɾus]* — アンチウイルス(ソフト)
> 例: Instale um antivírus no seu computador. — コンピューターにアンチウイルスをインストールしてください。

**0039. firewall** *[ˈfajɐwɔw]* — ファイアウォール
> 例: O firewall bloqueou o acesso. — ファイアウォールがアクセスをブロックした。

**0040. driver** *[ˈdɾajveɾ]* — ドライバー(ソフト)
> 例: Preciso atualizar o driver da impressora. — プリンターのドライバーを更新する必要がある。

**0041. atualização** *[atwalizaˈsɐ̃w̃]* — アップデート
> 例: Há uma nova atualização disponível. — 新しいアップデートが利用可能だ。

**0042. versão** *[veɾˈsɐ̃w̃]* — バージョン
> 例: Qual versão você está usando? — どのバージョンを使っていますか。

**0043. licença** *[liˈsẽsɐ]* — ライセンス
> 例: A licença do software expirou. — ソフトウェアのライセンスが期限切れになった。

**0044. instalar** *[ĩstaˈlaɾ]* — インストールする
> 例: Vou instalar esse programa agora. — 私は今からこのプログラムをインストールする。

**0045. desinstalar** *[dezĩstaˈlaɾ]* — アンインストールする
> 例: Preciso desinstalar esse aplicativo. — このアプリをアンインストールする必要がある。

**0046. configurar** *[kõfiɡuˈɾaɾ]* — 設定する
> 例: Ainda preciso configurar o e-mail. — まだメールを設定する必要がある。

**0047. configuração** *[kõfiɡuɾaˈsɐ̃w̃]* — 設定
> 例: Mudei as configurações de privacidade. — 私はプライバシー設定を変更した。

**0048. interface** *[ĩteɾˈfasi]* — インターフェース
> 例: A interface do aplicativo é muito intuitiva. — そのアプリのインターフェースはとても直感的だ。

**0049. ícone** *[ˈikoni]* — アイコン
> 例: Clique no ícone para abrir. — 開くにはアイコンをクリックしてください。

**0050. janela** *[ʒaˈnɛlɐ]* — ウィンドウ
> 例: Abri várias janelas ao mesmo tempo. — 私は同時に複数のウィンドウを開いた。

**0051. menu** *[meˈnu]* — メニュー
> 例: A opção está no menu de configurações. — そのオプションは設定メニューにある。

**0052. botão** *[boˈtɐ̃w̃]* — ボタン
> 例: Clique no botão verde para confirmar. — 確認するには緑のボタンをクリックしてください。

**0053. atalho** *[aˈtaʎu]* — ショートカット
> 例: Criei um atalho na área de trabalho. — 私はデスクトップにショートカットを作成した。

**0054. plugin** *[pluˈɡĩ]* — プラグイン
> 例: Instalei um plugin para melhorar o site. — 私はサイトを改善するためにプラグインをインストールした。

**0055. extensão** *[estẽˈsɐ̃w̃]* — 拡張機能/拡張子
> 例: Adicionei uma extensão ao navegador. — 私はブラウザに拡張機能を追加した。

**0056. backup** *[baˈkapi]* — バックアップ
> 例: Sempre faço backup dos meus arquivos. — 私は常にファイルのバックアップを取る。

**0057. arquivo** *[aɾˈkivu]* — ファイル
> 例: Não consigo abrir este arquivo. — このファイルを開けない。

**0058. pasta** *[ˈpastɐ]* — フォルダ
> 例: Organizei os documentos em pastas. — 私は書類をフォルダに整理した。

**0059. formato** *[foɾˈmatu]* — 形式
> 例: Qual formato você prefere, PDF ou Word? — PDFとWord、どちらの形式がいいですか。

**0060. compactar** *[kõpakˈtaɾ]* — 圧縮する
> 例: Vou compactar os arquivos antes de enviar. — 送る前にファイルを圧縮する。

**0061. descompactar** *[dʒiskõpakˈtaɾ]* — 解凍する
> 例: Descompacte o arquivo ZIP primeiro. — まずZIPファイルを解凍してください。

**0062. digitar** *[dʒiʒiˈtaɾ]* — 入力する、タイプする
> 例: Digite sua senha aqui. — ここにパスワードを入力してください。

**0063. clicar** *[kliˈkaɾ]* — クリックする
> 例: Clique duas vezes no ícone. — アイコンをダブルクリックしてください。

**0064. arrastar** *[ahasˈtaɾ]* — ドラッグする
> 例: Arraste o arquivo para a pasta. — ファイルをフォルダにドラッグしてください。

**0065. salvar** *[sawˈvaɾ]* — 保存する
> 例: Não esqueça de salvar o documento. — 書類を保存するのを忘れないで。

**0066. abrir** *[aˈbɾiɾ]* — 開く
> 例: Não consigo abrir esse aplicativo. — このアプリを開けない。

**0067. fechar** *[feˈʃaɾ]* — 閉じる
> 例: Feche todas as janelas abertas. — 開いているすべてのウィンドウを閉じてください。

**0068. editar** *[ediˈtaɾ]* — 編集する
> 例: Preciso editar essa foto. — この写真を編集する必要がある。

**0069. copiar** *[kopiˈaɾ]* — コピーする
> 例: Copie o texto e cole aqui. — テキストをコピーしてここに貼り付けてください。

**0070. colar** *[koˈlaɾ]* — 貼り付ける
> 例: Cole o link no chat. — チャットにリンクを貼り付けてください。

**0071. recortar** *[hekoɾˈtaɾ]* — 切り取る
> 例: Recorte esse trecho do texto. — そのテキストの一部を切り取ってください。

**0072. excluir** *[eskluˈiɾ]* — 削除する
> 例: Excluí o arquivo por engano. — 私は誤ってそのファイルを削除した。
> 注意: 口語では「deletar」もよく使う。

**0073. reiniciar** *[hejniˈsjaɾ]* — 再起動する
> 例: Vou reiniciar o computador. — コンピューターを再起動する。

**0074. formatar** *[foɾmaˈtaɾ]* — フォーマットする
> 例: Precisei formatar o computador. — 私はコンピューターをフォーマットする必要があった。

**0075. baixar** *[bajˈʃaɾ]* — ダウンロードする
> 例: Baixei o aplicativo ontem. — 昨日そのアプリをダウンロードした。

**0076. enviar** *[ẽviˈaɾ]* — 送信する、アップロードする
> 例: Enviei o arquivo por e-mail. — 私はメールでファイルを送信した。

**0077. conectar** *[konekˈtaɾ]* — 接続する
> 例: Não consigo conectar ao Wi-Fi. — Wi-Fiに接続できない。

**0078. desconectar** *[dʒiskonekˈtaɾ]* — 切断する
> 例: Ele se desconectou da reunião. — 彼は会議から切断された(退出した)。

**0079. ligar** *[liˈɡaɾ]* — 電源を入れる、電話する
> 例: Ligue o computador, por favor. — コンピューターの電源を入れてください。

**0080. desligar** *[dʒizliˈɡaɾ]* — 電源を切る
> 例: Desligue o notebook antes de guardar. — 片付ける前にノートパソコンの電源を切ってください。

**0081. senha** *[ˈseɲɐ]* — パスワード
> 例: Esqueci minha senha de novo. — 私はまたパスワードを忘れた。

**0082. usuário** *[uzuˈaɾju]* — ユーザー
> 例: O número de usuários cresceu muito. — ユーザー数が大きく増加した。

**0083. login** *[loˈɡĩ]* — ログイン

**0084. logout** *[loˈɡawtʃi]* — ログアウト
> 例: Não esqueça de fazer logout. — ログアウトするのを忘れないで。

**0085. cadastro** *[kaˈdastɾu]* — 登録
> 例: Preciso completar meu cadastro. — 私は登録を完了させる必要がある。

**0086. perfil** *[peɾˈfiw]* — プロフィール
> 例: Atualizei meu perfil na rede social. — 私はSNSのプロフィールを更新した。

**0087. rede social** *[ˈhedʒi soˈsjaw]* — ソーシャルネットワーク、SNS
> 例: Ele passa muito tempo nas redes sociais. — 彼はSNSに多くの時間を費やしている。

**0088. mensagem** *[mẽˈsaʒẽj]* — メッセージ
> 例: Te enviei uma mensagem ontem. — 私はあなたに昨日メッセージを送った。

**0089. notificação** *[notifikaˈsɐ̃w̃]* — 通知
> 例: Recebi muitas notificações hoje. — 私は今日たくさんの通知を受け取った。

**0090. nuvem** *[ˈnuvẽj]* — クラウド
> 例: Salvo meus arquivos na nuvem. — 私はファイルをクラウドに保存する。

**0091. domínio** *[doˈminju]* — ドメイン
> 例: Comprei um novo domínio para o site. — 私はサイト用に新しいドメインを購入した。

**0092. hospedagem** *[ospeˈdaʒẽj]* — (ウェブ)ホスティング
> 例: A hospedagem do site custa por mês. — サイトのホスティングは月額でかかる。

**0093. URL** *[u ˈɛhi ˈɛli]* — URL
> 例: Copie a URL do site. — サイトのURLをコピーしてください。

**0094. cookie** *[ˈkuki]* — クッキー(Web)

**0095. cache** *[ˈkaʃi]* — キャッシュ

**0096. largura de banda** *[laɾˈɡuɾɐ dʒi ˈbɐ̃dɐ]* — 帯域幅
> 例: A largura de banda está limitada. — 帯域幅が制限されている。

**0097. velocidade** *[velosiˈdadʒi]* — 速度

**0098. Wi-Fi** *[ˈwaj faj]* — Wi-Fi

**0099. dados móveis** *[ˈdaduz ˈmɔvejs]* — モバイルデータ通信

**0100. conexão** *[konekˈsɐ̃w̃]* — 接続

## 101〜200(プログラミング)

**0101. programação** *[pɾoɡɾɐmaˈsɐ̃w̃]* — プログラミング
> 例: Estou aprendendo programação sozinho. — 私は独学でプログラミングを学んでいる。

**0102. código** *[ˈkoʒiɡu]* — コード
> 例: Este código tem um erro. — このコードにはエラーがある。

**0103. linguagem de programação** *[lĩˈɡwaʒẽj dʒi pɾoɡɾɐmaˈsɐ̃w̃]* — プログラミング言語
> 例: Python é uma linguagem de programação popular. — Pythonは人気のプログラミング言語だ。

**0104. algoritmo** *[awɡoˈɾitʃimu]* — アルゴリズム
> 例: Esse algoritmo é muito eficiente. — このアルゴリズムはとても効率的だ。

**0105. função** *[fũˈsɐ̃w̃]* — 関数
> 例: Essa função retorna um número. — この関数は数値を返す。

**0106. variável** *[vaɾiˈavew]* — 変数
> 例: Criei uma variável para guardar o total. — 私は合計を保存する変数を作った。

**0107. constante** *[kõsˈtɐ̃tʃi]* — 定数
> 例: Essa constante não muda de valor. — この定数は値が変わらない。

**0108. loop** *[ˈlupi]* — ループ
> 例: O programa entrou em loop infinito. — プログラムが無限ループに入った。

**0109. condicional** *[kõdʒisjoˈnaw]* — 条件分岐
> 例: Usei um condicional para verificar o valor. — 私はその値を確認するために条件分岐を使った。

**0110. array** *[aˈhej]* — 配列
> 例: Adicione o item ao array. — その項目を配列に追加してください。
> 注意: ポルトガル語で「vetor」とも言うが、開発現場では英語の array がよく使われる。

**0111. lista** *[ˈlistɐ]* — リスト
> 例: A lista está vazia. — そのリストは空だ。

**0112. objeto** *[obˈʒɛtu]* — オブジェクト
> 例: Cada objeto tem suas próprias propriedades. — それぞれのオブジェクトは独自のプロパティを持つ。

**0113. classe** *[ˈklasi]* — クラス
> 例: Criei uma nova classe em Python. — 私はPythonで新しいクラスを作成した。

**0114. método** *[ˈmɛtodu]* — メソッド
> 例: Esse método não está funcionando. — このメソッドは機能していない。

**0115. biblioteca** *[bibljoˈtɛkɐ]* — ライブラリ
> 例: Instalei uma nova biblioteca no projeto. — 私はプロジェクトに新しいライブラリをインストールした。

**0116. framework** *[ˈfɾẽjwɔɾki]* — フレームワーク
> 例: Esse framework facilita o desenvolvimento web. — このフレームワークはウェブ開発を容易にする。

**0117. compilador** *[kõpilaˈdoɾ]* — コンパイラ
> 例: O compilador encontrou um erro de sintaxe. — コンパイラが構文エラーを見つけた。

**0118. depurador** *[depuɾaˈdoɾ]* — デバッガー
> 例: Use o depurador para encontrar o erro. — エラーを見つけるためにデバッガーを使ってください。

**0119. bug** *[ˈbaɡi]* — バグ
> 例: Encontramos um bug crítico no sistema. — 私たちはシステムで重大なバグを見つけた。

**0120. teste** *[ˈtestʃi]* — テスト
