# 頻出語彙リスト

ポルトガル語(ブラジル式)の頻出語彙5000語と、IT関連用語300語をまとめた辞書形式のリスト。[lessons/](../lessons/)のレッスンとは独立した参照資料で、単語を引いて発音・意味・使い方を確認する用途を想定している。

## 収録内容と注意点

- 各語には **発音(IPA)**、**意味**、**例文と和訳**、**注意点(あれば)** を記載する。
- 「頻度順位」は特定のコーパスを厳密に統計処理したものではなく、一般的な学習用頻度リストや実際の使用感をもとにした目安の順位である。上位(概ね1〜300位程度)は冠詞・前置詞・代名詞などの機能語が中心になる。これは実際の頻度統計でも共通する傾向。
- `o/os`、`a/as`、`um/uma` のように性・数で変化する語や、`do/da/no/na` のような前置詞+冠詞の縮約形([レッスン12](../lessons/12-preposicoes-contracoes/README.md)参照)も、実際の頻度リストにならい個別の語として1エントリで数えている。
